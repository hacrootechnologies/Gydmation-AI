# Changelog

Updates arrive with the same two commands: `docker compose pull`, then `docker compose up -d`. Your data is kept.

## 1.0.7 — 18 October 2026
- **Faster first message.** The first message after an install, update or restart no longer waits for one-time loading: the app prepares in the background as soon as it starts.
- **More reliable Pro requests.** Pro model requests are packed so that website firewalls no longer block large workflows, with a clearer message if a request is ever refused.

## 1.0.6 — 17 October 2026
- With no AI key added yet, the app now says so clearly ("add an API key") instead of asking for more detail.

## 1.0.5 — 17 October 2026
- Greetings such as "Hello Gydmation" get an instant reply and are no longer mistaken for build requests.
